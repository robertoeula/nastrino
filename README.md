# Nastrino

**Roberto Eula**  
*SIL Open Font License, 1.1*

Nastrino is an experiment, drawn by hand with japanese paper tape; born on paper but built for screens. A **tape-face**, an unconventional handwritten typeface.
#### Nastrino family contains (for now):

* Display (lowercase-only)
